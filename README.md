# Spotify Lyrics Crosshair (Fabric, Minecraft 1.21.11)

Zeigt synchronisierte Songtexte des laufenden Songs unter dem Fadenkreuz an.
Kein Spotify-Login und kein Premium nötig: Der Mod liest den Song aus der Windows-Mediensteuerung.
Voraussetzung: Windows + Spotify-Desktop-App.

Befehle: /lyrics on|off|toggle · status · reload
/lyrics scale <0.3-4> · y <px> · width <px> · lines <davor> <danach> · offset <ms> · speed <1-40> · shadow <true|false>
/lyrics color highlight <RRGGBB> · color normal <RRGGBB>
Einstellungen liegen in config/spotifylyrics.json.
